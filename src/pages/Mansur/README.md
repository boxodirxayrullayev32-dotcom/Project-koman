# Mansur

Bu papkada Mansur ishlaydi.

## Mansurning ishi

Mansur 2 ta sahifani qiladi:

- Bosh sahifa - Kunlikish
- Vakansiyalar sahifasi

## Juda sodda qilib

Tasavvur qil:

- bu sening xonang
- sen xonani chizasan
- ichidagi div, card, hero va footer’ni sen joylaysan

## Nima qilish kerak

1. Bosh sahifadagi katta hero blokni qil.
2. Vakansiyalar sahifasidagi card va filterlarni qil.
3. Header va routerga tegma.
4. Faqat o‘zingning page’laringni to‘ldir.
