# Aziz

Bu papkada Aziz ishlaydi.

## Azizning ishi

Aziz 2 ta sahifani qiladi:

- Ish qidirish sahifasi
- Kompaniyalar sahifasi

## Juda sodda qilib

Bu xuddi rasm bo‘yashga o‘xshaydi.

- Men joyini tayyorlab qo‘ydim
- Sen ichini chiroyli qilib bo‘yaysan

## Nima qilish kerak

1. Chap filter panelini qil.
2. Ish cardlarini joyla.
3. Kompaniya cardlarini qur.
4. Header va routerga tegma.
